# Quick guide: Reception

One page. Keep it at the workstation. Your super-user answers questions first; then IT.

## Your day

1. Search first. Type a name, phone, ID number, hospital number or old card number in **Patients**. Register a new person only if no one matches.
2. To register: **Patients, New patient**. Both names, date of birth, sex and phone are needed. If the system lists possible duplicates, open each before saving a new record.
3. Add the visit in **Today's queue**: choose the clinic and the person joins the queue. The registration fee is added to the bill by itself.
4. Check payer details (cash, SHA, insurer, company) and the member number before the patient leaves for the clinic.
5. A mistake in a name or date: use **Edit** on the patient. Never register the same person twice to fix it.

## If something goes wrong

- A patient is not found: search by phone, then by old card number. Still nothing: register, but read the duplicate list first.
- Any problem at all: **Problems, Report a problem**. Do not type patient names; use the hospital number.
- Server down: use the paper forms (**Paper forms**), call IT, and type the paper in afterwards with the real time of each event.
- Always sign out when you leave the screen. Your account is your signature in the audit trail.
